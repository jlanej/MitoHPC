how these calls are made

Each sample's circular-aware chrM alignment is scanned for split reads (reads whose two halves map across a deletion junction). Junctions are clustered to base-pair breakpoints. A deletion is reported PASS either when a coverage drop and the junction agree (SVCLAIM=DJ) or when the split-read junction alone is strong and clean (SVCLAIM=J — valuable because mtDNA read depth is finicky). Heteroplasmy (VAF) is the coverage-dosage fraction (AFC, shown here), with the junction-read fraction (AFJ) as corroborating evidence; their agreement is a QC signal (AFDIFF). The breakpoint microhomology / direct repeat (e.g. the 13 bp repeat of the common deletion) is reported as HOMLEN/DELCLASS. See docs/SV_METHODS.md.

glossary — definitions of terms used in this report
VAF (variant allele fraction) / heteroplasmy
Fraction of mtDNA molecules carrying the deletion (0–100%). The colour scale and the "VAF" shown here are the coverage-dosage estimate AFC (below) — the standard heteroplasmy measure for large mtDNA deletions; the junction estimate AFJ is reported as corroborating evidence.
Class I / II / III (DELCLASS)
Breakpoint-homology class, a clue to the deletion mechanism: Class I = the breakpoints sit in a perfect direct repeat ≥5 bp (e.g. the 13 bp repeat of the common deletion — slipped-strand mispairing); Class II = 1–4 bp microhomology; Class III = no breakpoint homology (blunt). Larger homology = the breakpoint can sit anywhere within the repeat, so its position is reported as imprecise.
HOMLEN / HOMSEQ
Length and sequence of that breakpoint microhomology / direct repeat (drives the Class above).
AFC — coverage VAF (primary)
Heteroplasmy from the dosage loss: AFC = 1 − trimmed-median(depth inside) / trimmed-median(depth in flanks), computed over D-loop/origin/homopolymer/NUMT-masked, transition-excluded windows. This is the reported VAF.
AFJ — junction VAF (evidence)
AFJ = JR / (JR + SR), where SR counts wild-type reads aligned contiguously across the breakpoint. Used to confirm the deletion and gate calls (the coverage drop must be backed by a proportional junction), not as the primary load.
AFDIFF
|AFJ − AFC| — how far the two estimates disagree. Large values flag amplification bias or a duplication/artifact masquerading as a deletion (a QC signal).
JR / SR
JR = number of distinct split (junction) reads spanning the deletion breakpoint; SR = wild-type spanning reads (the AFJ denominator at the breakpoints).
JSUP — split-read evidence tier
A depth-independent curation lens for the junction itself: HIGH = consistent breakpoint, ≥ the read threshold, two-strand support; MOD = a clean, consistent junction but low read count or one-strand (a credible low-level event — a handful of reads all clipping at the same base); LOW = scattered breakpoint sizes (likely a mapping/NUMT artifact). Filter to HIGH/MOD (with PASS only off) to review low-heteroplasmy junctions that have strong split-read evidence but no read-depth signal. Backed by SRCONS (size consistency, microhomology-invariant) and SRSB (strand balance).
CVGR
Coverage ratio = median depth inside the deletion / median depth in the flanks. ≤0.9 means a ≥10% coverage drop (the corroboration gate).
SVCLAIM
Which evidence supports the call: DJ = the split-read junction and the coverage drop agree; J = split-read junction only (no confirming coverage drop).
PASS & filters
PASS via either the DJ path (coverage drop corroborated by a proportional junction) or the J path (junction-strong: clean, well-supported split reads, no coverage drop required). Non-PASS reasons: lowJR (too few junction reads), no_cvg_drop (no ≥10% coverage drop), low_dosage (coverage-dosage AF below threshold), lowAFJ (corrected junction VAF below the floor), unexplained_drop (coverage drop not backed by a proportional junction — a likely artifact), fragile_weakJ (D-loop/NUMT/origin breakpoint without strong junction support), bigdel_weakJ (very large deletion with weak junction support), WRAP (breakpoint at the artificial origin / origin-crossing; deletion-vs-duplication unresolved), lowDP (flanking depth below threshold).
tags / flags
COMMON = matches the common deletion del4977; REPEAT = breakpoint in the del4977 13 bp direct repeat; NUMT / HP / DLOOP = breakpoint overlaps a known NUMT-like site / homopolymer run / control region (D-loop); WRAP = breakpoint near the origin. Flags annotate; they do not by themselves reject a call (except WRAP).
common deletion (del4977)
The canonical ~4977 bp "common" mtDNA deletion (m.8470_13447), flanked by a 13 bp direct repeat; accumulates with age in post-mitotic tissue.
HGVS
Approximate deletion span in Human Genome Variation Society (HGVS) notation on the revised Cambridge Reference Sequence (rCRS, NC_012920.1).
NUMT
Nuclear mitochondrial DNA segment — a mtDNA-derived paralogue in the nuclear genome; reads from NUMTs are the classic source of spurious mtDNA structural calls (suppressed upstream by competitive alignment, and flagged here).
