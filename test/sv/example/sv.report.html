how these calls are made

Each sample's circular-aware chrM alignment is scanned for split reads (reads whose two halves map across a deletion junction). Junctions are clustered to base-pair breakpoints; a deletion is reported PASS only when the split-read junction is corroborated by a coverage drop between the breakpoints. Heteroplasmy (VAF) is estimated two ways — the junction-read fraction (AFJ, shown here) and the coverage ratio (AFC) — and their agreement is a QC signal. The breakpoint microhomology / direct repeat (e.g. the 13 bp repeat of the common deletion) is reported as HOMLEN/DELCLASS. See docs/SV_METHODS.md.

glossary — definitions of terms used in this report
VAF / heteroplasmy
Fraction of mtDNA molecules carrying the deletion (0–100%). The colour scale and the "VAF" shown here are the coverage-dosage estimate AFC (below) — the standard heteroplasmy measure for large mtDNA deletions; the junction estimate AFJ is reported as corroborating evidence.
Class I / II / III (DELCLASS)
Breakpoint-homology class, a clue to the deletion mechanism: Class I = the breakpoints sit in a perfect direct repeat ≥5 bp (e.g. the 13 bp repeat of the common deletion — slipped-strand mispairing); Class II = 1–4 bp microhomology; Class III = no breakpoint homology (blunt). Larger homology = the breakpoint can sit anywhere within the repeat, so its position is reported as imprecise.
HOMLEN / HOMSEQ
Length and sequence of that breakpoint microhomology / direct repeat (drives the Class above).
AFC — coverage VAF (primary)
Heteroplasmy from the dosage loss: AFC = 1 − trimmed-median(depth inside) / trimmed-median(depth in flanks), computed over D-loop/origin/homopolymer/NUMT-masked, transition-excluded windows. This is the reported VAF.
AFJ — junction VAF (evidence)
AFJ = JR / (JR + SR), where SR counts wild-type reads aligned contiguously across the breakpoint. Used to confirm the deletion and gate calls (the coverage drop must be backed by a proportional junction), not as the primary load.
AFDIFF
|AFJ − AFC| — how far the two estimates disagree. Large values flag amplification bias or a duplication/artifact masquerading as a deletion (a QC signal).
JR / SR
JR = number of distinct split (junction) reads spanning the deletion breakpoint; SR = wild-type spanning reads (a coverage proxy at the breakpoints).
CVGR
Coverage ratio = median depth inside the deletion / median depth in the flanks. ≤0.9 means a ≥10% coverage drop (the corroboration gate).
SVCLAIM
Which evidence supports the call: DJ = the split-read junction and the coverage drop agree; J = split-read junction only (no confirming coverage drop).
PASS & filters
PASS = a clustered split-read junction corroborated by a coverage drop, meeting the read/depth thresholds. Non-PASS reasons: lowJR (too few junction reads), no_cvg_drop (no ≥10% coverage drop — where genuine low-heteroplasmy events land), WRAP (breakpoint at the artificial origin / origin-crossing; deletion-vs-duplication unresolved), lowDP (flanking depth below threshold).
tags / flags
COMMON = matches the common deletion del4977; REPEAT = breakpoint in the del4977 13 bp direct repeat; NUMT / HP / DLOOP = breakpoint overlaps a known NUMT-like site / homopolymer run / control region (D-loop); WRAP = breakpoint near the origin. Flags annotate; they do not by themselves reject a call (except WRAP).
common deletion (del4977)
The canonical ~4977 bp "common" mtDNA deletion (m.8470_13447), flanked by a 13 bp direct repeat; accumulates with age in post-mitotic tissue.
HGVS
Approximate deletion span in HGVS notation on the rCRS reference (NC_012920.1).
